# 住宅情報館参考サイト 分析レポート

## 1. This Report's Purpose

このレポートは、参考サイト `https://www.jyuutakujyouhoukan.com/` のローカルミラーをもとに、ゆめハウスサイト改善へ使える要素と使わない方がよい要素を整理するためのもの。目的はコピーではなく、情報設計・写真戦略・CV導線・信頼形成・技術実装の観点を分解して、次の設計判断に使える形にすること。

対象ローカルURL:

```text
http://127.0.0.1:8125/www.jyuutakujyouhoukan.com/index.html
```

対象フォルダ:

```text
reference-sites/jyuutakujyouhoukan-full-2026-05-21/www.jyuutakujyouhoukan.com
```

## 2. User Request

ユーザーは、この参考サイトを「あらゆる視点で」詳しく解析・分析したいと依頼した。さらに、視点ごとに subagent を使ってもよいと明示した。

今回の分析では、以下の4視点を並行で確認した。

- ビジュアルデザイン / 写真 / 余白 / UI
- 情報設計 / 導線 / CV / 不動産ビジネス
- 技術実装 / HTML / CSS / JS / SEO / アクセシビリティ
- コピーライティング / 信頼形成 / 地域性 / ゆめハウスへの応用

## 3. Context

ゆめハウス側では、既存サイトの写真・素材がやや安っぽく見えることが課題になっている。ユーザーは、外部素材やAI生成も含めて、街中・自然・暮らし系の画像を使って空気感を作る方向に関心がある。

この参考サイトは、新潟市の不動産会社サイトで、トップに地域の大判写真を使い、物件検索・物件一覧・土地選びのコツ・選ばれる理由・購入までの流れ・FAQ・会社情報・スタッフ・問い合わせへ導線を作っている。

## 4. Overall Evaluation

総合評価は 82 / 100。

強いのは、情報設計と信頼形成。不動産サイトとして「初めての人が不安になるポイント」をかなり丁寧に潰している。トップから、物件、土地選び、理由、購入フロー、FAQ、会社、スタッフ、問い合わせへ進める流れが自然。

一方で、技術実装と更新性は古い。WordPressテーマとしては一貫性があるが、jQuery系の重複読み込み、巨大CSS/JS、重要コピーの画像化、H1重複、iframe依存などは、ゆめハウスで真似しない方がよい。

## 5. Before / After Experience

参考前のゆめハウス改善論点:

- 店舗写真や素材の質感が弱い
- 不動産サイトとしての安心感・実在感・地域感が不足しやすい
- 物件を見る人、ローン相談したい人、売却相談したい人の導線が混ざりやすい

参考サイトから得られる改善方向:

- ファーストビューは店舗写真単体より、地域・街・暮らしを見せる方が強い
- 物件カードだけでなく、購入までの流れ・FAQ・選び方コンテンツが必要
- スタッフ写真、会社情報、電話CTA、問い合わせ導線を全ページで反復すると安心感が出る
- ゆめハウスでは「月々支払い」「ローン不安」「校区」「駐車台数」など、もっと生活とお金に近い言葉へ寄せるとよい

## 6. Information Architecture

トップの大まかな流れ:

1. 地域性のある大判ファーストビュー
2. おすすめ売買物件
3. 新着売買物件
4. 売却/買取系バナー
5. 土地・物件選びのコツ
6. 選ばれる理由
7. 購入までの流れ
8. FAQ
9. トピックス
10. 会社/スタッフ導線
11. 電話・問い合わせCTA

この順番は、不動産サイトとしてかなり実用的。いきなり会社の理念を語るのではなく、まず物件を見る。その後、失敗しない選び方、会社を選ぶ理由、購入フロー、FAQで不安を下げる。

ユーザー別導線:

- 初回訪問者: トップ写真 → 物件 → 土地選び → 選ばれる理由 → FAQ → 問い合わせ
- 購入検討者: 物件検索 / 物件一覧 → AtHome iframe → 電話 / 問い合わせ
- 分譲地検討者: 固定CTA / 分譲地バナー → 分譲地一覧 / 分譲地詳細
- 売却相談者: 売却バナー → 外部サイト寄り

弱点は、サイトの言葉が「売るひと買うひと」なのに、実際の構造は購入者中心で、売却は外部バナー頼みになっていること。ゆめハウスでは「買いたい」「売りたい」「ローン相談」「賃貸管理」などを明確に分けるべき。

## 7. Visual Design

確認した代表素材:

- `img/top/mainvisual.jpg`: 2800x1040 の地域大判写真
- `img/top/mainvisual_sp.jpg`: 1280x1300 のスマホ用写真
- `img/top/maincatch.png`, `maincatch_02.png`: コピー画像
- `img/title/title_default.jpg`: 下層共通見出し背景
- `img/page/reason/reason_img_*.jpg`
- `img/page/flow/flow_img_*.jpg`
- `img/page/staff/staff_img_00.jpg`, `staff_img_01.jpg`
- `wp-content/uploads/...`: 物件・分譲地写真

良い点:

- ファーストビューで地域の空気感が出る
- 余白が大きく、地方不動産会社らしい落ち着きがある
- オレンジ系CTAで行動箇所がわかりやすい
- 実スタッフ写真があり、相談先の顔が見える
- 分譲地詳細では現地写真が多く、実物感がある

弱い点:

- 重要コピーが画像化されており、SEO・更新性・可読性で弱い
- 下層ページのファーストビューが共通背景で、ページ固有の印象が弱い
- オレンジ、赤茶、クリーム、青系バナーが混ざり、ブランド色はやや散る
- 物件写真の中には文字焼き込み・素材感があり、現代的な高級感は弱い
- search/list が iframe 依存で、デザイン体験が外部サービスに切り替わる

ゆめハウスでは、構図は参考にしてよい。ただし、コピーは画像化せず HTML テキストで作る。色は2〜3色に絞る。下層ごとに写真カテゴリを変える。

## 8. Copy and Trust

このサイトが作っている信頼:

- 新潟市の不動産会社である
- 20年以上の実績がある
- 物件選び、土地選び、購入手順に詳しい
- 会社概要、スタッフ、許認可、アクセスが見える
- 電話でもフォームでも相談できる

不安解消コンテンツ:

- 土地選びのコツ: エリア、地盤、形状、建ぺい率、容積率
- 購入までの流れ: 相談、買付、ローン、契約、決済
- FAQ: 相談だけ、諸費用、仲介手数料、頭金、抵当権、重要事項説明

ゆめハウスに応用するなら、「理想の住まい」だけでは弱い。もっと具体的にする。

- 月々支払いから無理なく探す
- 住宅ローンが不安な段階から相談できる
- 駐車台数、校区、通勤、生活動線で選ぶ
- 頭金、諸費用、事前審査、借入可能額を一緒に確認する
- 熊本市、益城、嘉島、菊陽、合志など実営業エリア名を出す

## 9. Conversion Design

CTAはかなり多い。

- ヘッダー電話
- ヘッダー問い合わせ
- スマホ電話ボタン
- 物件検索
- 物件一覧
- 土地選びのコツ
- 固定サイドCTA
- 分譲地固定CTA
- フッター電話
- フッター問い合わせ

強い点は、ユーザーがどこで不安になっても電話・問い合わせへ戻れること。弱点は、CTAの種類がやや多く、売却・購入・分譲地の優先順位が混ざること。

ゆめハウスでは以下の3本に整理するとよい。

1. 物件を見る
2. ローン・購入相談をする
3. 売却 / 買取 / 管理の相談をする

物件カードには、単なる価格ではなく、月々支払い・駐車台数・校区・見学可否・新着/値下げバッジを入れるとゆめハウスらしくなる。

## 10. Technical Analysis

参考になる点:

- `header`, `nav`, `main`, `section`, `footer`, `figure`, `dl` など、大枠のHTMLは読みやすい
- `sec-`, `box-`, `unit-` でセクション・箱・小部品を分ける考え方は使える
- Yoast SEO、OGP、Twitter Card、JSON-LD、パンくずの基本出力がある
- Contact Form 7 は最低限のフォーム支援機能を持つ
- フッターCTAを全ページに置く構造は有効

真似しない点:

- `jquery` と `jquery-migrate` の重複読み込み
- DataTables のCSS/JSバージョン不一致
- Contact Form 7 / DataTables / Modernizr / wp-embed を全ページに積む
- 約278KBの巨大 `common.css`
- 約69KBの `common-min.js` にSlick, Lightbox, Waypoints, AjaxZip3, matchHeight, DataTables初期化をまとめる
- ロゴ `h1` とページタイトル `h1` の重複
- `a:focus { outline:none }`
- ハンバーガーが `button` ではなく `div`
- フォームで `label for` と input id の明示接続が弱い
- iframeに `title` がない箇所
- 物件検索・一覧を全面的にAtHome iframeへ任せる

ゆめハウスでは、導線とページ構造は参考にしてよいが、実装は現代的に軽く作るべき。

## 11. What To Copy / What Not To Copy

真似してよい:

- 地域性のあるファーストビュー
- 物件カードを先に見せる順番
- 土地/物件選びの教育コンテンツ
- 選ばれる理由を3点で要約する構造
- 購入までの流れ
- FAQ
- スタッフ写真と代表挨拶
- 全ページ共通の電話・問い合わせCTA
- 会社概要、アクセス、許認可をきちんと載せる

真似しない:

- 画像化された見出しコピー
- 汎用下層FVの使い回し
- 色数の増えすぎ
- iframeだけの物件検索
- 巨大CSS/JS
- jQuery前提の古いUI
- アクセシビリティの弱いメニュー/フォーム
- 売却と購入の導線が混ざる構成

## 12. Yume House Direction

ゆめハウスに落とすなら、参考サイトの「地域密着・安心・購入フロー・FAQ」をベースにしつつ、訴求は以下へ寄せる。

- 住宅ローン相談に強い
- 月々支払いから探せる
- 熊本の生活動線で選べる
- 校区・駐車場・通勤・買い物・病院まで具体的に見る
- 物件見学前でも相談できる
- 売却/買取/賃貸管理も入口を分ける

必要な画像カテゴリ:

- 熊本の街並み、住宅地、生活道路
- 家族の生活感がある外部素材/AI素材
- 実物件の外観、室内、駐車場、前面道路
- 周辺施設、学校、公園、スーパー、病院
- スタッフ写真、相談風景、ローン説明風景
- 会社外観、店舗内、駐車場

## 15. Risks and Next Steps

残るリスク:

- ローカルミラーは静的取得なので、WordPress管理画面やフォーム送信、AtHome iframe内部の完全挙動までは分析対象外。
- 参考サイトの画像・文章・CSSは著作物なので、ゆめハウスへそのまま流用しない。
- 参考サイトは新潟向けなので、熊本のゆめハウスでは地域語彙と写真カテゴリを作り直す必要がある。

次の一手:

1. ゆめハウス用のトップ構成案を作る。
2. 「買う」「売る」「ローン相談」「賃貸管理」の導線を分ける。
3. 必要画像リストを作り、実写真 / 外部素材 / AI生成素材に分類する。
4. 現在の静的HTMLを、今回の情報設計に合わせて段階的に置き換える。
